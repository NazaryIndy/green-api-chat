# WhatsApp Chat — React

Небольшой веб-интерфейс для отправки и получения текстовых сообщений в **WhatsApp** через **GREEN-API**.

Проект выполнен в рамках тестового задания на позицию **Frontend Developer (React)**.

> В качестве мессенджера выбран WhatsApp, что допускается условиями тестового задания.

## Возможности

- подключение к GREEN-API по `idInstance` и `apiTokenInstance`;
- проверка авторизации инстанса перед началом работы;
- создание чата по номеру телефона;
- отправка текстовых сообщений;
- получение входящих текстовых сообщений через HTTP API;
- отображение исходящих и входящих сообщений;
- поддержка входящих сообщений расширенного текстового типа;
- поддержка URL внутри сообщений;
- автоматическая прокрутка к последнему сообщению;
- адаптивный интерфейс для desktop и mobile;
- клавиатурная навигация по основным элементам интерфейса.

Интерфейс выполнен в минималистичном стиле по мотивам веб-версии мессенджера, с сохранением минимального набора функций, необходимого для выполнения задания.

## GREEN-API

Для интеграции с WhatsApp используется **GREEN-API**.

### Отправка сообщений

Для отправки сообщений используется метод `SendMessage`.

Пользователь указывает номер телефона получателя в интерфейсе:

```text
79000000000
```

Приложение использует соответствующий `chatId` при отправке сообщения:

```json
{
  "chatId": "<chat-id>",
  "message": "Привет!"
}
```

Фактический `chatId` входящего чата определяется из данных GREEN-API (`senderData.chatId`) после получения первого сообщения.

Приложение поддерживает отправку только текстовых сообщений, что соответствует требованиям тестового задания.

### Получение сообщений

Для получения входящих сообщений используется **HTTP API** GREEN-API.

Приложение работает по следующему сценарию:

1. отправляет запрос `ReceiveNotification`;
2. получает входящее уведомление;
3. определяет `chatId` отправителя;
4. проверяет, относится ли сообщение к текущему чату;
5. преобразует данные GREEN-API во внутренний формат сообщения;
6. отображает сообщение в интерфейсе;
7. удаляет обработанное уведомление через `DeleteNotification`;
8. продолжает ожидать следующие сообщения.

Для ожидания новых уведомлений используется `receiveTimeout` в режиме long polling.

Запрос `ReceiveNotification` поддерживает `AbortController`, поэтому ожидающий HTTP-запрос корректно отменяется при изменении состояния компонента или отключении получения уведомлений.

## Поддержка текстовых сообщений

Приложение работает только с текстовыми сообщениями.

Поддерживаются:

- обычные текстовые сообщения;
- входящие сообщения расширенного текстового типа;
- URL внутри текста.

Ссылки в сообщениях распознаются на уровне интерфейса и отображаются как кликабельные ссылки.

Отдельный тип сообщения для ссылок не используется — исходящий текст отправляется через стандартный `SendMessage`.

Медиафайлы, документы, аудио и другие типы сообщений не обрабатываются.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер:

```bash
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале.

В интерфейсе необходимо указать:

- `idInstance`;
- `apiTokenInstance`.

Перед началом работы приложение проверяет состояние инстанса через `GetStateInstance`. Работа продолжается только для авторизованного инстанса.

## Конфигурация GREEN-API

URL API указывается в:

```text
src/shared/api/greenApi.ts
```

В текущей реализации используется общий хост-роутер:

```ts
const GREEN_API_URL = 'https://api.green-api.com';
```

При использовании другого инстанса необходимо указать соответствующий `apiUrl`, предоставленный GREEN-API.

> `idInstance` и `apiTokenInstance` не хранятся в `localStorage` или других постоянных хранилищах браузера. Они используются только в текущей сессии приложения.

## Обработка ошибок

Приложение обрабатывает основные ошибки пользовательского сценария:

- некорректные credentials;
- неавторизованный GREEN-API инстанс;
- ошибка подключения к API;
- ошибка отправки сообщения;
- некорректный номер телефона.

Ошибки отображаются непосредственно в интерфейсе без вывода credentials или других чувствительных данных в консоль.

## Ограничения

Проект намеренно реализован как минимальный интерфейс для выполнения тестового задания.

Не поддерживаются:

- история чатов после перезагрузки страницы;
- несколько сохранённых чатов;
- поиск по чатам;
- групповые чаты;
- медиафайлы и документы;
- голосовые сообщения;
- редактирование и удаление сообщений;
- статусы сообщений;
- авторизация пользователей в самом приложении;
- постоянное хранение credentials.

## GREEN-API API

В проекте используются следующие методы GREEN-API:

- `GetStateInstance` — проверка состояния инстанса;
- `SendMessage` — отправка текстового сообщения;
- `ReceiveNotification` — получение входящих уведомлений;
- `DeleteNotification` — удаление обработанного уведомления.

Подробная информация о работе API доступна в официальной документации GREEN-API.
